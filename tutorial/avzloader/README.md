# AvZLoader 文档

AvZLoader 将编译为 DLL 的 AvZ 脚本作为模组管理，支持自动加载、多个模组同时运行、热加载／卸载，以及按游戏用户和关卡筛选运行。

本目录说明 AvZLoader **2.0.0** 的加载器实现，基于 AvZ **2.9.2**。加载器的独立更新记录见 [CHANGELOG_LOADER.md](../../CHANGELOG_LOADER.md)。普通脚本使用本版本的头文件和静态库重新编译即可接入，不需要修改 `AScript`，也不需要自行实现加载器的导出函数。未安装加载器时，重新编译的脚本仍支持原来的独立注入流程。

## 三个需要区分的状态

**DLL 驻留**表示模块仍在进程中；**允许业务运行**表示当前筛选和生命周期允许执行脚本回调；**会话有效**表示框架仍保有某次选卡／战斗的状态。这三个状态分别管理。

例如，修改配置让某个模组不再匹配当前用户时，DLL 仍驻留，同一局的队列也保留，但业务回调暂停。若随后返回主菜单，管理逻辑仍会结束这次会话并清理旧队列。将 DLL 移出 `mods` 则会触发停止和卸载流程。

## 版本与边界

完整的会话清理、等待取消和安全卸载协议需要用当前版本重新编译模组。具备原有模组导出接口的旧 DLL 仍可加载，但不能据此获得新框架内部的生命周期保护；缺少清理确认协议时，目录热卸载会保持等待。

多个 DLL 共享一个游戏进程和游戏状态。加载器管理调度与模块寿命，不隔离模组对游戏内存的写入，也不自动解决选卡、炮序、补种等脚本之间的冲突。
